# BandScene

## 실행과 조작
Assets/Scenes/BandScene.unity를 열고 Play. ← / ↑ / → 입력, 결과 화면의 다시 연주 버튼 또는 R로 재시작한다. 음악이 없는 20초 타이밍 테스트이다.

## 구성
- 초록 쾅 / 빨강 락 / 파랑 붐의 세 레인과 방향 노트를 사용한다.
- 배경 sortingOrder -100, 레인 -20, 노트 20, 판정선 30, 패널 40으로 분리하여 배경에 가려지지 않도록 한다.
- 기준 화면 16:9, 24×13.5 월드 단위. 다른 비율에서는 화면을 잘라내지 않고 여백을 둔다.
- 왼쪽 위 성공 횟수, 오른쪽 위 남은 시간, 판정선 바로 위 GOOD/MISS, 하단 키 안내를 표시한다.
- HUD는 실행 시 uGUI로 생성한다. 한글은 Assets/Fonts/NotoSerifKR-Regular.ttf를 사용한다.
- 1초 간격 생성, ±0.18초 GOOD, 오입력/놓친 노트 MISS. 판정된 노트는 목록에서 제거하여 중복 집계를 방지한다.
- 모든 노트의 판정 기회가 20초 안에 끝나도록 마지막 생성 시점을 제한한다.
- Inspector의 playDuration, spawnInterval, noteSpeed, hitWindow, judgementY로 조정한다. 현재 씬 판정선 Y는 -3.5이다.
- 씬 배치를 다시 적용할 때 DevilMarriage → Band → Repair Scene Layout 메뉴를 사용한다. 씬 객체와 에셋 GUID는 유지한다.
- 일반 스테이지 데이터/퍼즐/흐름은 변경하지 않았다. 지속 파일 관리 지침은 프로젝트 루트 AGENTS.md에 있다.

## 검증 (2026-11-10)
- Unity 컴파일 및 Play 화면 확인.
- 세 레인, 판정선, 성공/남은 시간 패널, 선명한 MISS, 조작 안내와 결과 화면을 캡처하여 확인.
- 실제 플레이의 성공 횟수 14회 표시를 확인.
- 자동 검증에서 놓친 노트 MISS, 20초 종료, 재시작 버튼 콜백을 확인했다. 에디터에서 주입한 키 입력 검증은 입력 업데이트 타이밍 문제로 통과하지 못했으며, 자동 키 테스트 성공으로 간주하지 않는다.
- 음악 및 캐릭터 아트는 추가하지 않았다.

## 화면 비율·화질 복원 (2026-11-16)
- Game 뷰는 Full HD 1920×1080(16:9)을 사용하고, 확대해서 잘리지 않도록 화면에 맞춘 배율로 본다.
- 잘못 눌린 배경 크기를 기획 기준 24×13.5 배치로 복원했다.
- BandScene 및 Band 노트 텍스처는 무압축·최대 4096·NPOT 크기 유지·밉맵 축소 제외를 적용했다.
- 다시 복원할 때 DevilMarriage → Band → Restore 16x9 and Image Quality 메뉴를 사용한다.
